# Artefacto Digital

O "Atlas de Espécies Extintas" é uma experiência interativa inspirada no site Radio Garden, concebida para demonstrar quais as espécies já foram extintas pela ação humana. Seguindo a lógica de ingredientes, o projeto combina múltiplos inputs: textos estruturados em formato JSON como matéria-prima descritiva e histórica; imagens estáticas para a textura do globo e fotografias das espécies; funções `random()` para a geração procedural do fundo estrelado; e a interação com o computador através do rato, permitindo navegar livremente pelo globo e selecionar marcadores. Estes dados alimentam a expressão central, baseada numa visualização 3D em p5.js com cálculo de coordenadas esféricas e projeção ortográfica. O resultado é um artefacto digital composto por um globo rotativo e um painel de informação lateral adaptativo.

*Nota de Transparência:* Como não tenho bases de programação e precisei de suporte para desenvolver o código, recorri a LLMs como ferramenta de auxílio, testando e ajustando o projeto ao longo do processo com essa ajuda.
