# Artefacto Digital

O "Atlas de Espécies Extintas" é uma experiência interativa concebida para demonstrar quais as espécies já foram extintas pela ação humana. Seguindo a lógica de ingredientes, o projeto combina múltiplos inputs: textos estruturados em formato JSON como matéria-prima descritiva e histórica; imagens estáticas para a textura do globo e fotografias das espécies; funções `random()` para a geração procedural do fundo estrelado; e a interação com o computador através do rato, permitindo navegar livremente pelo globo e selecionar marcadores. Estes dados alimentam a expressão central, baseada numa visualização 3D em p5.js com cálculo de coordenadas esféricas e projeção ortográfica. O resultado é um artefacto digital composto por um globo rotativo e um painel de informação lateral adaptativo.

*Nota de Transparência:* Recorreu-se a LLMs como ferramenta de aceleração para a estruturação do código e otimização do layout dinâmico. Todo o processo foi rigorosamente acompanhado, testado, compreendido e iterado pelo autor.
